# Launcher tile art

`<id>-app-art.png`: 1024 × 1024 transparent RGBA, one per catalogue product, referenced by
`tile.art` in `products/catalog.json`. They are generated by `brand/scripts/build-brand.py` from
`brand/icons/instrumenta-icons.js`, with clear space around the icon. Do not edit or replace them
by hand; change the glyph and rebuild. The launcher's own mark is `brand/instrumenta-mark.png`.

The v1 marks these replaced are in `brand/archive/v1/artwork/`.
